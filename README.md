# openssf-scorecard-lab
A sample project for learning OpenSSF Scorecard and improving software security.

[![OpenSSF Scorecard](https://api.scorecard.dev/projects/github.com/sagessesamuel214-spec/openssf-scorecard-lab/badge)](https://scorecard.dev/viewer/?uri=github.com/sagessesamuel214-spec/openssf-scorecard-lab)
## Usage
This educational repository demonstrates OpenSSF Scorecard.
No local installation is required. Open Actions, select the
Scorecard workflow, and open its latest run to view results.
Security findings appear under Security → Code scanning.

Fork the repository, create a branch, make your changes, and
open a pull request explaining their purpose and validation.

Contributions must use valid YAML and Markdown, pin GitHub
Actions to full commit hashes, and contain no passwords,
tokens, or other secrets. Check workflow changes for successful
execution and documentation changes using Markdown preview.
